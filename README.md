## 注意

- 两个版本订阅 id 不同，**不要同时添加**。
- 之前加过旧地址的，请**删除订阅后重新添加**（否则 GKD 保留旧的启用状态）。
- 合并结果不会自动跟随上游更新，上游更新后需重新合并构建。
